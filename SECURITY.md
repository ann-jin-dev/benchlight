# Security

This project runs agents with real compute on a single-user workstation. The threat
model and guardrails are in [docs/safety.md](docs/safety.md).

Please report a vulnerability privately through GitHub's "Report a vulnerability"
button on this repository rather than in a public issue. Useful reports include a way
for the public window to reveal private data, for the private notebook to be reached
from another origin, or for an unattended wake-up to exceed its allowlist or budget.
